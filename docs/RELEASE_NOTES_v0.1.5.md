# Moyo v0.1.5 · 更安静的写作界面

这个补丁版本专注于视觉层级和界面降噪，让功能仍然容易找到，但不再与文章内容争夺注意力。

## 更简洁的滚动切换

- “同步滚动”和“独立滚动”只显示文字。
- 移除前置箭头和图标，当前同步状态用一条细强调线表示。

## 更克制的视觉层级

- 恢复原文与覆盖原文降为轻量次要操作，保存副本继续作为主要操作。
- 顶部模式栏、编辑区标签、中间分栏和状态栏使用更轻的分隔线。
- 行号区域减少色块感，让正文区域更加连续。

## 更清爽的格式工具栏

- 移除每组工具外层的胶囊卡片。
- 文字、段落和工具之间改用轻量分隔线。
- 当前启用格式使用柔和底色与细描边，不再出现过重的实色按钮。
- 保留触屏尺寸、键盘快捷键和所有原有编辑功能。

## 验证

- 自动测试与正式 PWA 构建全部通过。
- 日间模式下完成桌面和平板宽度视觉检查。
