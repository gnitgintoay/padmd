# Moyo 使用指南

## 1. 安装到主屏幕

### iPad

使用 Safari 打开 <https://gnitgintoay.github.io/padmd/>，点击“分享”并选择“添加到主屏幕”。之后从主屏幕启动，界面会更接近独立应用。

### Android

使用 Chrome 打开在线地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。

## 2. 导入文档

- **导入 MD 文件**：选择一篇或多篇 Markdown，统一进入“未分类”。
- **导入文件夹**：尽量保留顶层文件夹和内部子文件夹结构。
- **导入 ZIP 文件夹**：在设备本机解压，只提取 Markdown 文档。

如果 Safari 没有返回原文件夹名称，Moyo 会建立“导入文件夹”“导入文件夹 2”等独立分组，避免文档散落。

每次文件夹导入都会形成独立的顶层分组。同名文件夹再次导入时，会自动显示为“文件夹名 2”“文件夹名 3”，不会悄悄混入旧文件夹。单独导入的 Markdown 始终进入“未分类 · 单独导入”。

导入只会创建浏览器本地副本，不会移动、覆盖或删除设备中的原文件。

## 3. 管理文件夹

点击文件夹右侧的“⋮”，或在触屏设备上长按文件夹，可以：

- 在此新建文档；
- 重命名文件夹；
- 移动文件夹；
- 将文件夹中的文档移到回收站。

移动到已经存在的同名文件夹时，Moyo 会先询问是否合并。合并只改变显示分类，不覆盖文档内容。

### 批量删除文档

点击文档库右上角的“选择”，勾选多篇文档后点击“移到回收站”。“全选”只选择当前搜索结果，方便先搜索某个名称或路径再批量处理。批量删除不会碰设备“文件”App 中的原文件，误删后仍可从 Moyo 回收站恢复。

## 4. 编辑与原文对照

- **单栏编辑**：只显示修改稿，适合日常写作。
- **原文对照**：左侧显示导入时的原文，右侧显示修改稿。
- 拖动中间分隔线可改变两栏比例；双击分隔线恢复为各占一半。
- 只有用户正在滚动的栏位会驱动另一栏同步，避免自动回弹。

格式工具栏插入的是 Markdown 语法。例如加粗仍保存为 `**文字**`，但编辑区会用粗体提示实际效果。

## 5. 保存机制

Moyo 有三种不同状态：

1. **有未备份的修改**：文字只在当前编辑状态中；
2. **恢复草稿已备份**：草稿已写入浏览器本地数据库，但没有覆盖原文件；
3. **已保存修改版副本**：浏览器下载了一份新的 Markdown 文件。

“恢复原文”会放弃修改稿，恢复为导入时内容。“保存副本”不会替换设备中的原文件。

## 6. 备份与恢复

点击左下角“备份全部”，Moyo 会生成包含当前文档的 ZIP 文件。建议：

- 重要修改完成后立即备份；
- 定期把备份保存到 iCloud Drive、网盘或电脑；
- 清理 Safari 网站数据之前先备份；
- 不要把浏览器本地副本当成唯一副本。

完整的备份包恢复功能仍在路线图中。目前可以解压备份 ZIP 后重新导入。

## 7. 常用快捷键

| 操作 | 快捷键 |
|---|---|
| 保存修改版副本 | `Command/Ctrl + S` |
| 加粗 | `Command/Ctrl + B` |
| 斜体 | `Command/Ctrl + I` |
| 查找替换 | `Command/Ctrl + F` |
| 新建文档 | `Command/Ctrl + N` |
| 导入文件 | `Command/Ctrl + O` |
| 撤销/重做 | 系统标准快捷键 |

## 8. 常见问题

### 为什么只能看到部分文件？

先确认左侧列表可以上下滑动。如果系统文件选择器没有提供完整文件夹，建议把文件夹压缩为 ZIP 后导入。

### 为什么修改没有写回原文件？

这是为了避免网页在后台静默覆盖资料，也是 iPad 浏览器文件权限的限制。请使用“保存副本”。

### 不同设备会自动同步吗？

不会。当前文档保存在各自浏览器中，需要通过 ZIP 备份手动迁移。

### 清理浏览器缓存会怎样？

清理该网站的数据可能删除本地文档库。离线资源缓存和文档数据库不是同一概念，但浏览器的“清除网站数据”通常会同时处理它们。
