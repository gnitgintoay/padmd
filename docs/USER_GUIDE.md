# Moyo 使用指南

## 1. 安装到主屏幕

### iPad

使用 Safari 打开 <https://gnitgintoay.github.io/padmd/>，点击“分享”并选择“添加到主屏幕”。之后从主屏幕启动，界面会更接近独立应用。

### Android

使用 Chrome 打开在线地址，在浏览器菜单中选择“安装应用”或“添加到主屏幕”。

## 2. 导入文档

- **导入 MD 文件**：选择一篇或多篇 Markdown，统一进入“未分类”。
- **导入文件夹**：尽量保留顶层文件夹和内部子文件夹结构。
- **导入 ZIP 文件夹**：在设备本机解压，只提取 Markdown 文档。

如果 Safari 没有返回原文件夹名称，Moyo 会建立“导入文件夹”“导入文件夹 2”等独立分组，避免文档散落。

每次文件夹导入都会形成独立的顶层分组。同名文件夹再次导入时，会自动显示为“文件夹名 2”“文件夹名 3”，不会悄悄混入旧文件夹。单独导入的 Markdown 始终进入“未分类 · 单独导入”。

再次导入同一路径的文档时，Moyo 会先区分完全相同、内容变化和全新文档。可以选择智能处理、跳过重复文档、用新文件更新 Moyo 内部原文，或把全部内容保留为独立副本。更新内部原文时，已有本地修改稿不会被覆盖。

导入只会创建浏览器本地副本，不会移动、覆盖或删除设备中的原文件。

## 3. 管理文件夹

点击文件夹右侧的“⋮”，或在触屏设备上长按文件夹，可以：

- 在此新建文档；
- 重命名文件夹；
- 移动文件夹；
- 将文件夹中的文档移到回收站。

移动到已经存在的同名文件夹时，Moyo 会先询问是否合并。合并只改变显示分类，不覆盖文档内容。

### 批量删除文档

点击文档库右上角的“选择”，勾选多篇文档后点击“移到回收站”。“全选”只选择当前搜索结果，方便先搜索某个名称或路径再批量处理。批量删除不会碰设备“文件”App 中的原文件，误删后仍可从 Moyo 回收站恢复。

选择多篇文档后也可以点击“移动分类”，输入例如“学习/课程”的目标路径；留空会把文档移动到 Moyo 根目录。

展开回收站后，可以勾选多篇文档并使用“恢复所选”或“删除所选”。批量彻底删除前会再次确认，完成后无法撤销。

### 搜索、最近与收藏

- 搜索框会同时查找文件名、路径、原文和修改稿正文；匹配文字会在结果中高亮。
- 点击正文搜索结果后，编辑器会跳到首次命中的文字。
- “最近”按最后打开时间显示最多 20 篇文档。
- 在文档右侧菜单选择“收藏”，之后可从“收藏”视图快速打开。

## 4. 编辑与原文对照

- **单栏编辑**：只显示修改稿，适合日常写作。
- **原文对照**：左侧显示导入时的原文，右侧显示修改稿。
- 新导入一篇 Markdown 时，原文和修改稿来自同一次文件读取，空行、空格、标点和末尾换行都会逐字符保留。只有后续编辑、恢复历史版本、覆盖原文或重复导入处理才会改变二者之一。
- **专注模式**：隐藏工作台、顶部操作和底部工具栏，只保留编辑内容；点击“退出专注”或按 `Esc` 返回。
- **大纲**：识别 `#` 至 `######` 标题，点击标题可跳到对应行；代码块中的 `#` 不会被误识别。
- **信息**：查看路径、来源、创建与修改时间、字数、收藏状态和草稿状态。
- 拖动中间分隔线可改变两栏比例；双击分隔线恢复为各占一半。
- 点击“同步滚动”可在两种方式间切换：开启时任意一栏都会带动另一栏；切换为“独立滚动”后，两栏可以分别查看。再次开启同步会重新对齐，并记住这项选择。
- 内容和两栏渲染宽度都相同时按像素同步；两栏宽度不同会产生不同换行高度，因此改为按阅读进度比例同步。想要逐行对照时，可双击中间分隔线恢复 50/50。
- 修改稿发生增删后同样按阅读进度比例同步。触摸、鼠标滚轮、触控板和键盘翻页都可以驱动同步，快速滑动会逐帧更新并在停止后校正最终位置。

格式工具栏分成三组：

- **文字**：加粗、斜体、高亮、行内代码和链接，只作用于选中的文字。再次点击同一个格式可以撤销，例如 `**文字**` 会恢复为 `文字`。
- **段落**：标题、无序列表、`1. 列表`、待办、引用和代码块。其中标题与列表类功能按 Markdown 规则作用于整行；即使只选中一行中的几个字，也会修改这一整行。`1. 列表`表示有序列表，选择多行时会自动生成 `1.`、`2.`、`3.` 连续编号，再次点击可撤销。
- **工具**：查找、撤销和重做。

当前选区使用明显的暖色阴影显示。光标或选区已经处于某种格式中时，相应按钮会高亮。格式工具栏插入的仍是 Markdown 语法，例如加粗保存为 `**文字**`，编辑区同时用粗体提示实际效果。

## 5. 保存机制

Moyo 有三种不同状态：

1. **有未备份的修改**：文字只在当前编辑状态中；
2. **恢复草稿已备份**：草稿已写入浏览器本地数据库，但没有覆盖原文件；
3. **已导出修改版副本**：浏览器下载了一份新的 Markdown 文件。

编辑器右上角提供两个独立操作：

- **保存副本**：默认保存方式。每次都会下载一份包含当前内容的新 Markdown 文件；旧副本不会跟着更新。
- **覆盖原文**：额外选项，仅在内容有修改时可用。当前修改稿会覆盖 Moyo 内部原文，成为以后“原文对照”和“恢复原文”的新基准。操作完成后可立即撤销。

“恢复原文”会放弃修改稿，恢复为当前的 Moyo 原文。以上操作都不会替换设备“文件”App里的真实文件。

## 6. 备份与恢复

点击左下角“备份全部”，Moyo 会生成包含当前文档的 ZIP 文件。建议：

- 重要修改完成后立即备份；
- 定期把备份保存到 iCloud Drive、网盘或电脑；
- 清理 Safari 网站数据之前先备份；
- 不要把浏览器本地副本当成唯一副本。

新版 Moyo 备份 ZIP 同时包含可直接阅读的 Markdown 和恢复元数据。使用“导入 ZIP 文件夹”选择 Moyo 备份时，会先显示备份时间、文档数量和同名文档，并允许逐篇选择。确认后，所选原文、修改稿、文件夹与历史版本会恢复到一个独立的“Moyo 恢复 日期”文件夹中，不会覆盖现有文档。

点击侧栏底部的备份状态，可以打开“存储与备份”中心，查看文档数量、Moyo 内容大小、浏览器占用、可用配额和最近完整备份时间。浏览器支持时，还可以申请加强本地存储保护。

每次导入文件、文件夹或 ZIP 后，Moyo 会显示检查数量、成功数量、未导入数量和实际存放位置。

## 7. 历史版本

覆盖原文、恢复原文或恢复旧版本前，Moyo 会自动保留关键内容，每篇最多 10 个。点击文档右侧“⋮”并选择“历史版本”，可把旧内容恢复为修改稿；当前原文不会被直接覆盖。

## 8. 常用快捷键

| 操作 | 快捷键 |
|---|---|
| 打开保存方式 | `Command/Ctrl + S` |
| 加粗 | `Command/Ctrl + B` |
| 斜体 | `Command/Ctrl + I` |
| 查找替换 | `Command/Ctrl + F` |
| 新建文档 | `Command/Ctrl + N` |
| 导入文件 | `Command/Ctrl + O` |
| 撤销/重做 | 系统标准快捷键 |

## 9. 常见问题

### 为什么只能看到部分文件？

先确认左侧列表可以上下滑动。如果系统文件选择器没有提供完整文件夹，建议把文件夹压缩为 ZIP 后导入。

### 为什么修改没有写回原文件？

这是为了避免网页在后台静默覆盖资料，也是 iPad 浏览器文件权限的限制。请使用“保存副本”。

### 不同设备会自动同步吗？

不会。当前文档保存在各自浏览器中，需要通过 ZIP 备份手动迁移。

### 同一篇文档能在两个窗口同时编辑吗？

可以打开，但不建议同时修改。另一窗口写入恢复草稿后，当前窗口会显示更新提醒；如果当前窗口还有未备份修改，重新载入前会再次确认。

### 清理浏览器缓存会怎样？

清理该网站的数据可能删除本地文档库。离线资源缓存和文档数据库不是同一概念，但浏览器的“清除网站数据”通常会同时处理它们。
