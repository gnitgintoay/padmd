## 依赖说明

测试框架已升级至 Vitest 5.1，PWA 插件已升级至 2.0。完整开发依赖审计仍报告 4 个低等级问题，均来自 Workbox 构建链依赖的 `deepmerge`，上游当前没有不破坏 PWA 构建的修复版本；这些代码只在开发构建阶段运行，不会进入用户浏览器。生产依赖审计为 0。

## 当前限制

- iPad Safari 不能让静态 PWA 长期持有任意来源文件的写入权限，因此默认保存 Moyo 内部草稿并导出副本。
- 数据保存在当前浏览器 IndexedDB；清除网站数据可能删除文档，必须定期使用“备份全部”。
- 文档没有端到端加密，同一浏览器环境的其他使用者可能访问本地文档库。
- 图片附件、HTML 编辑、跨设备同步和多人协作不属于当前稳定范围。
- 特别大的文档库进行全文搜索时仍可能产生可感知等待。

## 发布后维护

GitHub Actions 会在 main 分支推送和 Pull Request 时自动运行安装、测试、构建与生产依赖审计。后续功能变更应同时更新使用指南、CHANGELOG、隐私边界与对应自动测试。
