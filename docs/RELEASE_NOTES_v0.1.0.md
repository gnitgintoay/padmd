# Moyo v0.1.0 · Public Beta

Moyo 的第一个公开测试版本已经可以在 iPad、Android 平板和手机浏览器中使用，并可安装到主屏幕。

在线体验：<https://gnitgintoay.github.io/padmd/>

## 这一版可以做什么

- 导入单篇 Markdown、整个文件夹或 ZIP 文件夹，并保留文件夹层级。
- 在单栏中编辑，或打开原文对照并拖动分栏宽度。
- 使用全文搜索、最近文档、收藏、标题大纲、查找替换和 Markdown 格式工具栏。
- 批量移动、批量移入回收站，并在回收站中批量恢复或彻底删除。
- 默认保存新的 Markdown 副本，也可选择用修改稿覆盖 Moyo 内部原文。
- 导出包含原文、修改稿、文件夹和历史版本的完整 ZIP 备份。
- 离线使用，并通过 Safari 或 Chrome 添加到主屏幕。

## 数据与隐私

Moyo 没有账号、广告、统计分析或业务后端。Markdown 内容只保存在当前浏览器的 IndexedDB 中，不会上传到 Moyo 服务器。

请注意：清除浏览器网站数据可能删除本地文档。重要内容应定期使用“保存副本”或“备份全部”导出。

## 已知限制

- 不能静默写回 iPad“文件”App 中的来源文件。
- 图片附件、HTML 导出和跨设备同步尚未实现。
- 大型文档库的全文搜索仍有性能优化空间。
- 多标签页只提供修改提醒，不提供实时协作和自动冲突合并。

完整变化见 [CHANGELOG](../CHANGELOG.md)，使用方法见 [USER_GUIDE](USER_GUIDE.md)。
