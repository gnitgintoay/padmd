# Moyo 隐私说明

最后更新：2026-11-12

这份说明描述当前开源版本的实际行为，不替代 GitHub Pages、浏览器或操作系统各自的隐私政策。

## Moyo 处理哪些数据

导入或创建文档时，Moyo 会在当前浏览器保存 Markdown 原文与草稿、名称、逻辑文件夹路径、相关时间和界面设置。

## 数据保存在哪里

文档保存在当前设备、当前浏览器来源的 IndexedDB 数据库 `padmd-web` 中。应用资源由 Service Worker 缓存，用于离线启动。

当前版本没有用户账号、业务后端或云端文档数据库，也没有广告、分析或遥测代码。

## 哪些情况会产生网络请求

- 首次打开和应用更新时，浏览器会从 GitHub Pages 获取程序资源；
- GitHub Pages 会按照其政策处理 IP 地址和常规访问日志；
- Markdown 文档内容不会因为上述资源请求自动上传。

## 谁可能看到本地文档

- 使用不同设备或不同浏览器存储环境的人，通常无法读取彼此的 IndexedDB；
- 使用同一设备、同一浏览器环境的人可以打开同一文档库；
- 设备被解锁、浏览器配置被共享或恶意软件取得本地访问权限时，文档可能暴露；
- 当前数据未加密，不适合密码、证件、医疗记录或涉密资料。

## GitHub Pages 同源限制

浏览器按照协议、主机名和端口区分来源，不按照 URL 路径隔离 IndexedDB。当前在线版位于 `gnitgintoay.github.io/padmd/`，同一 `gnitgintoay.github.io` 主机下的其他页面理论上属于同一来源。

项目计划迁移到独立来源并评估本地加密。在此之前，不应将 Moyo 当作高安全级别的加密保险箱。

## 删除和备份

- “移到回收站”只改变 Moyo 本地副本；
- “彻底删除”从 Moyo 的 IndexedDB 删除记录；
- 清除浏览器网站数据可能删除整个本地文档库；
- “备份全部”生成的 ZIP 没有加密，应由用户自行安全保管。

## 隐私承诺的变更

未来如果增加同步、账号、分析或任何文档上传能力，必须默认保持关闭或取得明确同意，明确说明数据目的与去向，并在发布前更新架构和隐私文档。
