# Moyo v0.1.2 · 原文对照精确对齐

这个补丁版本集中修复原文对照模式的滚动错位。

## 这次修复了什么

- 原文与修改稿内容相同时，两栏统一字体、行高、可用文字宽度和上下留白，相同行处于同一纵向位置。
- 相同内容采用逐像素同步；修改稿已有增删时，采用阅读进度比例同步。
- 不再依赖鼠标先进入某一栏，iPad 触控、触控板、滚轮和键盘翻页都能双向同步。
- 打开原文对照和拖动分栏宽度后，原文栏自动跟随修改稿的当前阅读位置。

## 验证

- 15 项自动测试全部通过。
- 使用 120 行相同内容进行浏览器实测，两栏内容高度一致；分别从左右两栏滚动后，滚动位置误差均为 0 像素。

## 使用提醒

如果已经把 Moyo 添加到主屏幕，发布后请联网打开一次；若仍显示旧行为，请完全退出 Moyo 后重新打开，让离线缓存更新。
