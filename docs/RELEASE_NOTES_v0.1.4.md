# Moyo v0.1.4 · 可切换的流畅对照滚动

这个补丁版本让原文对照既能同步阅读，也能按需分别查看两栏，并减少长文档滚动时的卡顿和位置尾差。

## 同步与独立滚动

- 原文对照顶部增加“同步滚动”按钮。
- 点击后切换为“独立滚动”，左右两栏互不带动。
- 再次开启同步时，两栏会按当前阅读位置重新对齐。
- 滚动方式会保存在当前浏览器中，下次继续沿用。

## 对齐规则

- 新导入文档的原文与修改稿使用同一份读取结果，逐字符一致，不会主动删除段落、空行或文字。
- 内容和两栏宽度都一致时按像素同步。
- 两栏宽度不同会造成换行位置不同，此时按阅读进度比例同步；双击分隔线可恢复 50/50，便于逐行比较。
- 修改稿发生增删后也按阅读进度同步。

## 流畅度

- 连续滚动事件合并到浏览器动画帧内处理。
- 滚动时不再重复读取并比较整篇文档。
- 停止滚动后执行一次最终位置校正，消除快速滑动留下的细小偏差。

## 验证

- 22 项自动测试覆盖滚动计算、文档初始一致性、数据库、编辑器命令和重复导入。
- 浏览器实测确认同步模式两栏最终位置差为 0；独立模式只移动当前栏，恢复同步后重新对齐。
