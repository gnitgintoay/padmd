# Moyo v0.1.8 · 最终发布审计与工程加固

这一版本不改变已经确认的暖白/暖夜视觉方向，重点完成全项目检查、安全更新和发布工程加固。

## 稳定性

- 增加旧实验主题设置迁移，曾使用 v0.1.6 的浏览器会自动恢复暖夜主题。
- 增加迁移自动测试；当前共有 5 个测试文件、24 项测试。
- 浏览器实测长文档编辑、格式撤销、内部原文覆盖、同步/独立滚动、主题切换和工作台收起全部正常。

## 依赖与安全

- Vitest 升级至 5.1。
- Vite PWA 插件升级至 2.0。
- 更新受安全公告影响的 glob、minimatch 与相关构建依赖。
- 生产依赖安全审计为 0 个漏洞。

## GitHub 工程

- 新增 GitHub Actions，自动运行安装、测试、PWA 构建和生产依赖审计。
- 新增完整发布审计报告。
- 补齐 v0.1.6 历史记录，明确黑白蓝主题已经撤回。

完整检查结果见 [`FINAL_AUDIT_v0.1.8.md`](FINAL_AUDIT_v0.1.8.md)。
