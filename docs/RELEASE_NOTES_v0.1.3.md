# Moyo v0.1.3 · 更可靠的选区格式与更快的点击响应

这个补丁版本重做了 Markdown 格式工具栏的交互，并清理了两个会放大长文档点击延迟的热点。

## 格式工具栏

- 工具栏重新分成“文字 / 段落 / 工具”三组。
- 加粗、斜体、高亮、行内代码、链接和代码块会保留点击前的文字选区，只修改选中的文字。
- 再次点击同一个格式可以撤销，不会继续重复添加 Markdown 标记。
- 标题、无序列表、有序列表、待办和引用明确标注为整行格式。
- `1. 列表`现在明确表示有序列表，多行选择会自动连续编号。
- 当前格式按钮会显示启用状态，选区阴影在日间与夜间模式下都更加清晰。

## 响应速度

- 单纯移动光标或改变选区时，不再转换和统计整篇文档。
- 字数统计合并为短延迟更新，连续输入不会反复触发全文扫描。
- 打开文档时先呈现编辑器，再在后台写入最近打开信息，减少点击后的等待感。

## 验证

- 20 项自动测试全部通过。
- 浏览器实测确认局部加粗、再次点击撤销、行级有序列表和选区阴影正常。
- 2000 行、约 2.7 万字符的文档中，连续 20 次光标移动平均约 15 毫秒（包含自动化交互开销）。
