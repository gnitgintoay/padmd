# Moyo v0.1.6 · 黑白蓝高级主题

这一版本在原有暖白与暖夜主题之外，增加一套更冷静、更现代的黑白蓝主题。

## 黑白蓝视觉

- 接近纯黑的冷色画布，降低长时间写作时的环境亮度。
- 高对比白色正文，确保 Markdown 内容仍然是视觉中心。
- 蓝色仅用于主按钮、选中状态、光标、活动文档和同步状态。
- 猫耳品牌图标在该主题下自动转换为蓝色版本。
- 编辑器选区、活动行和 Markdown 高亮都使用专属蓝色层级。

## 主题切换

- 左上角主题按钮使用白、黑、蓝三个色点表示三套主题。
- 点击依次切换“暖白 → 暖夜 → 黑白蓝”。
- 当前主题的色点会放大，并显示切换提示。
- 主题选择保存在当前浏览器，下次打开自动恢复。

## 验证

- 三套主题均完成编辑与原文对照界面检查。
- 22 项自动测试与正式 PWA 构建全部通过。
