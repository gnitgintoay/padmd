# Moyo v0.1.1 · 更可靠的导入与恢复

这一版重点减少重复导入产生的混乱，并让完整备份恢复变得可检查、可选择。

## 新增

- 重复导入时识别完全相同、内容变化和全新文档。
- 提供智能处理、跳过所有重复、更新 Moyo 内部原文和全部保留副本四种方式。
- 更新内部原文时保留用户已有的本地修改稿，并保存重新导入前的历史版本。
- Moyo 备份恢复前展示备份时间、文档数量和同名文档数量。
- 可以全部选择、全部取消或逐篇勾选需要恢复的文档。

## 安全边界

所有比较、解压和恢复操作仍只在当前浏览器中完成，不会修改设备“文件”App 中的来源文件，也不会上传 Markdown 正文。
